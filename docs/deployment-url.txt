Live deployment

URL: https://ajaia-docs-production-4f33.up.railway.app/

Sign in with any of these accounts, the password is demo123 for all of them:
  alice@ajaia.test   owns a document shared with Bob and Carol
  bob@ajaia.test     editor on Alice's document, owns one of his own
  carol@ajaia.test   viewer on Alice's document, best for showing read only mode
  dan@ajaia.test     no documents, best for showing a fresh share

Hosted on Railway as a single Docker image, with a Supabase Postgres database.
The Angular build is compiled into the Spring Boot jar, so the whole product is
one service on one URL.

It also runs locally with two commands and no configuration, see README.md.
